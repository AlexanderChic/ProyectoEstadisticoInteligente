# Sistema Inteligente Estadístico para la Gestión Comercial de Abarrotería

Proyecto de Graduación — Universidad Mariano Gálvez de Guatemala  
Ingeniería en Sistemas | Autor: Francisco Alexander Chic Barrios | Carné: 9490-22-2503

## Descripción
Sistema web que aplica análisis estadístico (promedios móviles, tendencias y estadística 
descriptiva) sobre datos históricos de ventas e inventario de abarroterías, con el objetivo 
de mejorar la toma de decisiones de compra, reposición e inventario del propietario.

## Stack tecnológico
- Backend: Python + Flask
- Base de datos: SQL Server
- Análisis estadístico: Pandas + NumPy
- Gráficos: Chart.js
- Frontend: HTML + CSS + Bootstrap 5
- Control de versiones: Azure Repos (Git)

## Estructura del proyecto
- src/        → código fuente de la aplicación
- db/         → scripts SQL de base de datos
- docs/       → documentación del proyecto
- tests/      → pruebas unitarias

## Ramas
- main     → versión estable / producción
- develop  → desarrollo activo
